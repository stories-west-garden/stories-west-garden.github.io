# West Garden — истории участников

Готовый статический лендинг для публикации на Vercel.

## Структура
- `index.html` — лендинг
- `assets/video/` — видео историй 8–11
- `vercel.json` — настройки статической публикации

## Публикация
Загрузите содержимое этой папки в корень GitHub-репозитория и подключите репозиторий к Vercel. Framework Preset: Other / No Framework. Build Command и Output Directory оставьте пустыми.
